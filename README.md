## 🚀 Featured Projects

### 🎤 AI Mock Interview Platform

A multimodal AI-powered interview platform that analyses interview performance through speech recognition, emotion tracking, STAR-method scoring, filler-word detection, speaking rate (WPM) and downloadable PDF reports.

**Stack:** React, TypeScript, FastAPI, Gemini 2.5 Flash, DistilBERT, Hugging Face, Face-api.js

🔗 [Hugging Face Model](https://huggingface.co/Prathmesh0001/interview-AI) · [Source Code](https://github.com/Prathmeshkangane/interviewAi.git)

### 📚 AI Research Assistant – RAG over arXiv

An AI-powered research assistant that enables semantic search and question answering over 10,000 arXiv research papers using vector retrieval and LLM-generated answers. Includes Docker Compose deployment, MySQL integration, 30 pytest tests and GitHub Actions CI.

**Stack:** Python, Flask, RAG, FAISS, Sentence Transformers, Gemini, MySQL, Docker, pytest, GitHub Actions

🔗 [Source Code](https://github.com/Prathmeshkangane/AI-Research-Assistant.git)

### 🎧 Speech Emotion Recognition – EmoSense

Developed a stacked LSTM-based speech emotion classification model using MFCC and spectrogram features across 7 emotion classes. Trained and evaluated on the RAVDESS and TESS datasets, achieving approximately **81% test accuracy (Macro F1: 0.81)**.

**Stack:** Python, TensorFlow/Keras, LSTM, librosa, Streamlit

🔗 [Source Code](https://github.com/Prathmeshkangane/Emosense.git)
